# Rockfall Prediction IoT System

## Overview
IoT based rockfall prediction system using sensors to detect vibration/tilt and give early warning.  
Built with Arduino and simulated on Wokwi.

## Features
- Continuously monitors rock/slope vibration or tilt.
- Triggers buzzer and LED alert when readings cross safe limit.
- LCD shows status: SAFE / DANGER.
- Can be extended to send cloud / SMS alert.

## Hardware Used
- Arduino Uno
- MPU6050 / vibration or tilt sensor
- 16x2 I2C LCD
- Buzzer, LEDs, Resistors, Jumper wires
